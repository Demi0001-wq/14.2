# E-commerce Platform Foundation

This project implements the core classes for an e-commerce platform, focusing on Product and Category management.

## Features
- Encapsulation with private attributes.
- Property getters and setters with validation.
- Automated data loading from JSON.
- Comprehensive unit testing.

## Installation
Use poetry to install dependencies:
```bash
poetry install
```

## Usage
Run the main script to see the functionality:
```bash
python main.py
```

## Testing
Run tests with coverage:
```bash
pytest --cov=src
```
